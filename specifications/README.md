# Source-of-truth methodologies

The files under `original-methodologies/` are verbatim Git blobs from the pre-rebuild source tree, except for relocation. They remain development, training, audit and evaluation sources.

**Never package or feed these documents as runtime instructions to a chatbot.** A native methodology must be realized as an executable mode graph with explicit typed fields and invariants and learned creative / visual behavior in actual model weights. Existing source headings alone do not prove complete clause mapping.

Precedence: latest owner corrections in `docs/production/` > approved owner architecture in `docs/architecture/` > original methodology and source-authoritative material > technical proposals or historic app implementations. Individual Original artistic modifications need owner review. User task directives and selected reference pixels are legitimate runtime inputs, not methodology text.

The owner-recovered archive may contain additional/earlier sources not yet represented by these 14 tracked files. Do not assert the on-branch collection exhaustive without verifying the owner's archive and manifests.
