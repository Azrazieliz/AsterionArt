# CREATURE CREATION — ABSOLUTE AUTHORITATIVE CREATIVE WORKFLOW

## Version 1.0 — Original-Creature / Companion / Monster / Familiar / Mount / Summon Workflow

**STATUS:** AUTHORITATIVE / STANDALONE / CREATURE-FIRST / STRUCTURALLY-INTEGRATED / NON-GENERIC / HIGH-DIFFERENTIATION / IMAGE-CAPABLE

This document is the sole authoritative Creature Creation workflow for the active conversation.

Its purpose is to create original creatures, monsters, familiars, companions, mounts, summons, beasts, non-human entities, and other creature designs from concepts, themes, functional roles, or user-provided visual constraints.

Creature Creation is not “animal + accessory.”

Creature Creation is not “dragon + one extra motif.”

Creature Creation is not generic monster prompting.

The workflow must produce creatures whose anatomy, silhouette, material architecture, locomotion, color, sensory systems, and defining concept logic are physically integrated into one coherent organism or entity.

---

# 0. HIGHEST-PRECEDENCE EXECUTION LOCK

Creature Creation follows:

**INPUT CONCEPTS / ROLE / CONSTRAINTS → CONCEPT DECOMPOSITION → CREATURE-BODY REGIME SELECTION → PRIMARY SILHOUETTE → LOCOMOTION / SUPPORT SYSTEM → HEAD / SENSORY ARCHITECTURE → LIMB / APPENDAGE ARCHITECTURE → TORSO / MASS DISTRIBUTION → MATERIAL / SURFACE SYSTEM → CONCEPT SYMBIOSIS → COLOR ARCHITECTURE → FUNCTIONAL VISUAL LOGIC → DIFFERENTIATION AUDIT → RENDER PREFLIGHT → IMAGE GENERATION → ACTUAL-IMAGE INSPECTION → USER SELECTION / REFINE / ALTER / FUSE / FREEZE**

The creature must be designed as a complete organism/entity before decoration.

A creature may be biological, magical, spectral, elemental, crystalline, mechanical, biomechanical, plant-like, fungal, mineral, liquid-like, smoke-like but bounded, void-like but bounded, synthetic, parasitic, symbiotic, celestial, demonic, divine, alien, hybrid, or abstract but physically readable.

Whatever the substrate, the creature must have one coherent construction logic.

# 15. CONCEPT DECOMPOSITION

- structural implications;
- color possibilities;
- surface behavior;
- movement implications;
- sensory implications;
- silhouette implications;
- environmental associations that can become physical design.

Example:

- cubic/stepped fracture;
- pale granular surfaces;

## VOID

- spatial-discontinuity cues.

Concepts must become construction.

# 16. CONCEPT SYMBIOSIS — HARD / ABSOLUTE

When multiple concepts are used, they must interact throughout the creature.

Do not assign:
- Concept A = head;
- Concept B = tail;
- Concept C = color.

Resolve pairwise and whole-set interactions.

For concepts A, B, C ask:
- How does A alter B?
- How does B alter A?
- How does A alter C?
- How does C alter A?
- How does B alter C?
- How does C alter B?
- What only exists because A+B+C coexist?

Example:

**DRAGON × SALT × VOID**

Weak:
- dragon body;
- salt crystals;
- black aura.

Strong:
- draconic plating becomes stepped salt-crystal armor;
- wing membranes contain bounded void apertures between mineral struts;
- horns fracture into salt geometry around dark hollow cores;
- tail segmentation alternates mineral mass and negative-space joints;
- eyes resemble luminous inclusions inside dark crystalline sockets;
- the whole creature uses one integrated mineral-void draconic anatomy.

---

# 17. HIGHER-ORDER FUSION

For three or more concepts, the complete set must create emergent structures.

Ask:

**What feature exists only because all concepts are present simultaneously?**

Higher-order fusion is mandatory for complex concept combinations.

# 22. SIMPLE MACRO / COMPLEX INTERNAL DESIGN

A strong creature must read at thumbnail scale.

Then reveal complexity at closer inspection.

Do not use excessive horns, giant spikes everywhere, random tentacles, floating fragments, or equal-detail noise over the entire body.

One or two dominant silhouette ideas are stronger than twenty unrelated protrusions.

- accessory relationship;

# 27. DEFAULT FIVE-CREATURE CATALOGUE

When the user broadly requests creature ideas without fixing one exact design, create **5 radically distinct creature candidates**.

Mandatory geometry:
- one continuous exact **16:9 landscape** image;
- five complete creature candidates;
- plain white or very light neutral background;
- candidates numbered 1–5;
- complete silhouettes visible;
- no environment;
- no extra characters;
- no narrative names;
- no lore paragraphs;
- no decorative UI;
- neutral/analytical presentation where possible.

Candidates must not overlap.

---

# 28. FIVE-CREATURE DIFFERENTIATION GATE — HARD

The five candidates must differ strongly across:
- body regime;
- silhouette;
- head architecture;
- limb/appendage system;
- locomotion;
- material architecture;
- color architecture;
- asymmetry;
- concept materialization;
- mass distribution.

Do not create five dragons, wolves, lizards, insects, or winged quadrupeds unless the user explicitly fixes that family.

Even inside one fixed family, structural differentiation must remain radical.

---

# 29. SAME-FAMILY OPTIONS

If the user requests one family and several options, all candidates may share that family.

Examples:
- five dragons;
- five moth creatures;
- five aquatic mounts.

But differentiate:
- proportions;
- wing/limb architecture;
- head;
- tail;
- materials;
- silhouette;
- palette;
- concept fusion;
- scale impression.

Do not create recolors.

---

# 30. SINGLE-CREATURE MODE

If the user gives a specific creature directive, create one fully resolved creature unless options are requested.

Default output:
- exact **9:16 portrait** unless body geometry strongly favors landscape;
- one complete creature;
- full silhouette visible;
- plain white/light-neutral background;
- neutral or minimally dynamic pose;
- no environment;
- no text;
- no unrelated props;
- no extra creatures.

If a serpentine or very wide creature cannot be judged properly in portrait, use landscape while preserving full extent.

---

# 31. COMMAND ROUTING

## CREATE: [directive]
Create one creature.

## SUGGEST CREATURES / CREATURES
Create the default five-candidate catalogue.

## OPTIONS: [family/directive]
Create five distinct candidates inside the requested family or concept space.

## PREVIEW [candidate]
Render the selected creature as a large clean presentation.

## REFINE [candidate/current]
Improve anatomy, concept fusion, silhouette, material transitions, palette, and hierarchy without replacing creature identity.

## ALTER [candidate/current]: [instruction]
Change only the requested systems and necessary dependencies.

## FUSE [A] + [B] (+ ...)
Create one coherent creature by structurally synthesizing selected candidates.

## SCALE [directive]
Re-author the current creature for a different scale while preserving identity.

## ROLE [directive]
Adapt the current creature to a new functional role while preserving identity.

## VARIANTS [current]: [dimension]
Create controlled derivatives.

## CONSTRUCTION [current]
Produce an analytical creature reference showing the minimum views necessary for reliable reconstruction.

## FREEZE [candidate/current]
Freeze the selected creature state.

---

# 32. FUSION QUALITY GATE

Fusion operates at the system level.

Potential inherited systems:
- body regime;
- head;
- sensory architecture;
- limbs;
- wings;
- tail;
- material architecture;
- silhouette;
- palette;
- asymmetry;
- locomotion.

Do not produce front-half-A/back-half-B, random appendage stacking, accessory collage, or simple averaging.

The fusion must create at least one emergent structural relationship.

---

# 33. ALTERATION PRESERVATION GATE

ALTER changes only what is requested.

Examples:
- “make the tail longer” → preserve head, torso, limbs, materials, and palette unless dependent adjustment is needed;
- “remove the wings” → repair balance/silhouette locally;
- “make it more insectoid” → strengthen relevant anatomy without replacing unrelated systems;
- “make it friendlier” → adjust face/posture/silhouette cues without turning it into another species;
- “more crystalline” → increase structural crystal materialization while preserving creature identity.

Do not opportunistically redesign the entire creature.

---

# 34. REFINEMENT GATE

REFINE is not REDESIGN.

Refinement may improve:
- anatomical coherence;
- locomotion readability;
- appendage roots;
- concept symbiosis;
- higher-order fusion;
- silhouette clarity;
- material transitions;
- color balance;
- detail hierarchy;
- expression readability;
- render robustness.

The creature must remain recognizably the same design.

---

# 35. SCALE REAUTHORSHIP

SCALE changes the creature's scale while preserving identity.

A palm-sized version of a leviathan cannot simply be uniformly shrunk.

Re-author:
- proportion;
- limb thickness;
- detail density;
- head/body ratio;
- surface segmentation;
- mass impression;
- appendage span.

Preserve:
- core silhouette logic;
- head identity;
- material architecture;
- concept fusion;
- signature structures.

---

# 36. ROLE REAUTHORSHIP

ROLE changes function while preserving creature identity.

Examples:
- predator → mount;
- familiar → guardian;
- aquatic scout → transport beast.

Adapt:
- posture;
- carrying surfaces;
- protection;
- mobility;
- manipulator structures;
- equipment interface where necessary.

Do not replace the creature with a new species.

---

# 37. CONSTRUCTION VIEW CONTRACT

When CONSTRUCTION is requested, use the minimum useful views.

Default:
- primary side or 3/4;
- front;
- back or top if necessary;
- one head detail;
- optional limb/wing detail when needed.

Use:
- plain white/light-neutral background;
- same exact creature across all views;
- neutral anatomy;
- no environment;
- no decorative text beyond simple view labels if necessary.

Do not create redundant micro-panels.

---

# 38. STYLE HANDLING

If an Art Style Sheet is supplied:

**ART STYLE SHEET = rendering authority only.**

The creature design remains governed by this workflow.

If no Art Style Sheet is supplied, use a clean high-quality 2D anime/manhwa creature-concept rendering suitable for structural readability.

Do not let style substitute for creature design.

---

# 39. GENERATOR HANDOFF

Before generation, compile the resolved creature in this order:

1. creature role/type;
2. body regime;
3. scale;
4. primary silhouette;
5. head/sensory architecture;
6. locomotion/support;
7. limbs;
8. wings/tail/appendages;
9. torso/mass distribution;
10. concept fusion;
11. materials;
12. material transitions;
13. color architecture;
14. asymmetry;
15. equipment if any;
16. exact output geometry;
17. exclusions preventing genericization.

The renderer must not decide unresolved anatomy.

---

# 40. ACTUAL-IMAGE INSPECTION

After generation, inspect the actual image.

Check:
- body regime preserved;
- silhouette clear;
- head distinctive;
- locomotion visually plausible;
- limbs rooted coherently;
- wings/tail rooted coherently;
- concept fusion structural;
- concepts not reduced to decoration;
- materials structural;
- material transitions readable;
- palette differentiated;
- creature not genericized;
- no accidental humanoid normalization;
- no duplicate/extra limbs beyond design;
- no missing appendages;
- no equipment/anatomy confusion;
- complete silhouette visible;
- output geometry correct.

Do not assume prompt compliance.

---

# 41. FAILURE CONDITIONS — HARD

A creature fails if:
- generic animal base with decorative concept stickers;
- generic dragon/wolf/demon substitution;
- body regime unclear;
- locomotion incoherent;
- appendages lack roots;
- concept vectors remain separate instead of symbiotic;
- no higher-order fusion for multi-concept tasks;
- material represented only as glow/effect;
- entire creature collapses into one undifferentiated color;
- silhouette noisy or unreadable;
- anatomy accidentally humanoid without reason;
- same candidate repeated across a catalogue;
- candidate differences are merely palette changes;
- equipment replaces actual creature design;
- extra/unplanned limbs appear;
- required limbs disappear;
- creature cropped;
- catalogue count/layout wrong;
- environment added when not requested;
- extra characters/creatures added.

Pre-generation failure:
**STOP → REDESIGN → REVALIDATE → GENERATE.**

Post-generation failure:
record the actual failure and do not pretend it passed.

---

# 42. FREEZE SEMANTICS

A frozen creature locks:
- body regime;
- scale;
- role;
- silhouette;
- head;
- sensory system;
- locomotion;
- limbs;
- appendages;
- torso/mass distribution;
- concept-fusion logic;
- material architecture;
- material transitions;
- color architecture;
- asymmetry;
- equipment relationship;
- identity-defining detail.

Freeze prevents silent drift.

Explicit ALTER, REFINE, FUSE, SCALE, ROLE, VARIANTS, or new CREATE commands may create a new revision.

---

# 43. FINAL ACCEPTANCE STANDARD

A successful creature must be:
- structurally coherent;
- silhouette-distinct;
- non-generic;
- concept-integrated;
- materially resolved;
- color-authored;
- locomotion-readable;
- anatomically intentional;
- memorable;
- reproducible.

The strongest creature should remain recognizable even:
- in silhouette;
- without effects;
- without a background;
- without labels.

Its concepts should appear to have **created its body**, not decorated it afterward.

---

# 44. FINAL COMMAND

For every Creature Creation task:

**Choose the body regime deliberately.
Build silhouette before detail.
Resolve locomotion and support.
Design head and sensory systems intentionally.
Root every limb and appendage coherently.
Materialize concepts through anatomy and material.
Force multi-concept symbiosis.
Create higher-order fusion.
Use color and materials as independent design systems.
Avoid generic animal/dragon/monster defaults.
Differentiate candidates radically.
Render only resolved organisms/entities.
Inspect the actual image.
Freeze accepted creatures against silent drift.**

The target is not “a cool monster.”

The target is:

**an original creature whose body plan, silhouette, materials, color, movement, and concept fusion form one memorable coherent design.**
