# FEMINISATION METHODOLOGY — FEMALE-FIRST RECONSTRUCTION, ANCHOR PRESERVATION, MALE-TEMPLATE DESTRUCTION, AND DEFAULT LEVEL 4.5

## 0. Purpose

This methodology defines how to reconstruct a source character as female while preserving recognizability.

The target is **not**:
- a direct gender swap;
- the male character with breasts added;
- the male face softened slightly;
- the male haircut simply lengthened;
- the male outfit opened at the chest;
- the male transformation shell with female anatomy inserted.

The target **is**:

> **a newly authored female character built from the source character’s identity, after the male/source construction has been dismantled and forbidden from surviving as the structural template.**

The result must communicate:

> **“This is unmistakably the same character, but this version was designed as female from the beginning.”**

It must not communicate:

> **“This is the male character edited to look female.”**

This methodology applies to:
- named characters;
- named forms and transformations;
- image-only reference characters;
- human, armored, transformed, monstrous, hybrid, and supernatural characters.

### 0.1 Permanent Presentation Rule

All final images use one presentation only: **one full-body character on a 9:16 vertical plain pure-white background, with no text, panels, alternate views, scenery, or character-sheet elements.**

This is a permanent output constraint of the methodology, not a preference to be interpreted loosely.

---

## 1. The Core Law

The fundamental operation is:

**SOURCE CHARACTER / SOURCE FORM**  
→ **THOROUGH SOURCE STUDY**  
→ **IDENTITY EXTRACTION**  
→ **RECOGNITION ANCHOR LOCK**  
→ **MALE/SOURCE TEMPLATE DESTRUCTION**  
→ **BLANK-SLATE FEMALE AUTHORING**  
→ **ANCHOR REINTEGRATION**  
→ **LEVEL 4.5 REFINEMENT / FEMINISATION**  
→ **VALIDATION**  
→ **FINAL OUTPUT**

The key rule is:

> **Recognition anchors are concepts, not geometry.**

Preserve what makes the character recognizable.  
Do **not** preserve the exact male geometry that originally carried that recognition.

Example:
- Preserve **black upward Saiyan hair language**.
- Do **not** preserve **the exact male Goku spike map**.

Example:
- Preserve **orange gi / blue undershirt martial identity**.
- Do **not** preserve **the exact male gi cut, trouser silhouette, and torso fit**.

---

## 2. Three-Layer Reconstruction Model

Every reconstruction must explicitly pass through three layers.

### Layer A — Identity Layer
What must survive because it defines recognizability.

### Layer B — Destruction Layer
What must be destroyed because it is only the male/source implementation.

### Layer C — Female Creation Layer
What must be newly authored from scratch as a female design.

If Layer B is skipped or weak, the output will collapse back into male-template editing.

---

## 3. Source Authority and Research

### 3.1 Named Characters — Mandatory Research

When the user provides a named character or form, research is mandatory unless the user explicitly forbids it.

Establish, where available:
- face structure;
- eyes;
- hair color;
- hair architecture;
- physique class;
- costume architecture;
- signature colors;
- silhouette;
- weapons;
- transformation anatomy;
- horns;
- masks;
- holes/voids;
- markings;
- appendages;
- energy systems;
- form-specific material relationships;
- the exact elements viewers use for immediate recognition.

Do not rely on memory alone if the character can be researched.

### 3.2 Supplied Images

If the user supplies a reference image, that visible version is authoritative for whatever it clearly shows.

External research may supplement missing information, but it must not silently override the supplied version.

### 3.3 Image-Only / Unnamed Characters

If the source is an image only, extract identity from what is visible.
Do not invent unsupported lore, anatomy, or extra systems.

---

## 4. Identity Layer — Recognition Anchor Lock

Before any reconstruction, identify the character’s **recognition anchors**.

Recognition anchors may include:
- hair color;
- hair directionality / energy;
- eye color;
- facial attitude;
- species traits;
- signature colors;
- iconic clothing identities;
- weapon identities;
- transformation identities;
- silhouette concepts;
- mask systems;
- horn systems;
- markings;
- damage patterns;
- body voids;
- power effects;
- iconic asymmetries.

### 4.1 Anchors Must Be Abstracted

Anchors must be defined at the **concept level**, not the male-shape level.

Good anchor:
- “orange hair, aggressive forward energy, wild layered silhouette.”

Bad anchor:
- “preserve the exact original male bangs and spike placements.”

Good anchor:
- “horned full-face Hollow skull mask with black vertical markings.”

Bad anchor:
- “use a small horn accessory and forehead ornament.”

### 4.2 Hard Anchors vs Soft Anchors

#### Hard Anchors
Must survive clearly.
Examples:
- signature hair color;
- iconic form mask;
- horn count/type;
- signature weapon;
- defining color palette;
- defining transformation anatomy.

#### Soft Anchors
May be translated more freely.
Examples:
- exact seam placement;
- exact trouser cut;
- exact sleeve shape;
- exact male face planes;
- exact boot proportions.

---

## 5. Destruction Layer — Male / Source Template Destruction

This is a mandatory phase.

Explicitly identify what exists only because the source was designed male.
Destroy it as a structural template.

This may include:
- male face proportions;
- male jaw/chin logic;
- male brow ridge logic;
- male neck/shoulder proportions;
- male torso cage;
- male ribcage-to-pelvis ratio;
- male hip structure;
- male stance logic;
- male limb mass distribution;
- exact male hairstyle construction;
- exact male clothing fit;
- exact male armor geometry;
- exact male transformation shell.

### 5.1 Forbidden Survivals

The following are prohibited end states:
- the same male silhouette with breasts added;
- the same male face with softer eyelashes;
- the same male haircut with extra length;
- the same male outfit simply exposed more;
- the same male transformation with added female chest;
- the same male pose and construction with minor cosmetic edits.

### 5.2 Blank-Slate Gate

After destruction, the workflow must be able to describe the reconstruction **without depending on the male geometry**.

If the female version cannot be designed independently after this phase, the destruction phase failed.

---

## 6. Female Creation Layer — Blank-Slate Female Authoring

Now author the woman from scratch.

This is the **first real design stage**.
The male/source geometry must no longer be the scaffold.

Author independently:
- face;
- eyes;
- brows;
- lips;
- cheek/jaw balance;
- hair architecture;
- hair framing;
- volume;
- body class;
- shoulder/waist/hip relationships;
- musculature distribution;
- limb rhythm;
- feminine silhouette;
- cosmetics or equivalent refinement;
- garment design;
- armor design;
- transformation anatomy;
- gesture / presence.

### 6.1 Face

The female face must be independently designed.
It must not look like the male face with softened edges.

Preserve only the transferable identity:
- expression family;
- eye energy;
- temperament;
- intensity;
- recognition attitude.

### 6.2 Hair

Hair must be independently reconstructed.
Do not solve hair feminisation by just adding length.

Rebuild:
- strand architecture;
- framing;
- flow;
- weight;
- layering;
- silhouette rhythm;
- movement language.

### 6.3 Body

The female body must be newly authored.

It may be:
- petite;
- athletic;
- muscular;
- elegant;
- curvy;
- lean;
- mature;
- youthful-looking;
- monstrous;
- non-human;
- armored.

The correct choice depends on the source identity, not on a single default body type.

Bust size is optional and secondary.
It is never the primary proof of femininity.

### 6.4 Cosmetics and Equivalent Refinement

Increase femininity and refinement through:
- lashes;
- eyeliner;
- brow design;
- lip definition;
- complexion treatment;
- controlled blush;
- nail treatment;
- elegant facial shaping.

Where literal cosmetics are inappropriate, translate refinement into:
- mask line elegance;
- eye framing;
- cleaner contrast control;
- refined markings;
- cleaner material transitions;
- sharper or more deliberate surface rhythm.

---

## 7. Clothing Reconstruction — Female Outfit From Scratch

Clothing must be re-authored.
Do not keep the male outfit shell and merely open or crop it.

The sequence is:

**source costume identity**  
→ **extract costume anchors**  
→ **destroy male fit and male garment logic**  
→ **author a female costume from zero**  
→ **reintegrate costume anchors**

Preserve, where identity-critical:
- colors;
- symbols;
- material language;
- sash identity;
- cape identity;
- layer hierarchy;
- distinctive asymmetry;
- battle damage logic;
- weapon integration.

### 7.1 Clothing Reduction

Less coverage is a permitted and often useful tool, but it is **not the central mechanism of feminisation**.

The rule is:
- clothing may be reduced when it improves the female-authored design;
- reduced coverage must remain source-derived and coherent;
- clothing reduction must never be the substitute for actual reconstruction.

### 7.2 Prohibited Clothing Failures

Do not replace the source identity with:
- generic lingerie;
- generic bikini armor;
- generic fantasy pinup wear;
- unrelated evening dress;
- random “sexy anime girl” costume.

If the new outfit is more revealing, it must still look like it belongs to that exact character.

---

## 8. Armor Reconstruction

Armor must be rebuilt as armor designed for the female reconstruction.

Preserve identity through:
- motifs;
- heraldry;
- colors;
- plate language;
- material identity;
- key shoulder systems;
- gauntlets;
- greaves;
- weapon interface.

Rebuild:
- torso segmentation;
- waist logic;
- hip integration;
- chest architecture;
- thigh transitions;
- shoulder balance;
- plate rhythm;
- openness / exposure;
- female silhouette compatibility.

Do not make armor feminine merely by adding breast cups.

---

## 9. Transformation Reconstruction

Transformations require full reconstruction too.
A transformation must not stay male while only the base body is feminised.

Decompose the form into:
- hard recognition anchors;
- transformation anatomy;
- species logic;
- mask systems;
- horn systems;
- shell systems;
- markings;
- holes/voids;
- appendages;
- claws;
- eye changes;
- aura;
- energy framing;
- clothing destruction or replacement;
- form silhouette.

Then re-author the transformation as if that transformed female form had always existed.

### 9.1 Transformation Integrity Lock

Do not degrade complete forms into accessories.

Prohibited degradations:
- full mask → face ornament;
- full horn system → decorative horn;
- full transformed anatomy → normal woman with themed costume;
- canonical void/hole → cosmetic cutout;
- canonical body shell → ordinary dress;
- monstrous hands → normal hands with dark nails only.

### 9.2 Transformation Feminisation

Feminisation must propagate through:
- face/mask integration;
- horn rhythm;
- shell contour;
- torso construction;
- hip/pelvis design;
- limb contour;
- markings placement;
- appendage flow;
- clothing remnants;
- silhouette;
- surface refinement.

The form may remain terrifying, monstrous, alien, or severe.
Feminisation does not mean normalization.

---

## 10. Appeal, Refinement, and Feminisation

Feminisation is not the same thing as sexualisation.

A successful design may be:
- elegant;
- charming;
- beautiful;
- sharp;
- alluring;
- refined;
- imposing;
- cute;
- regal;
- feral;
- disciplined;
- severe.

Feminisation should be visible across:
- face;
- hair;
- silhouette;
- body design;
- garment authorship;
- transformation authorship;
- detailing;
- refinement.

The wrong shortcut is:
- larger bust;
- more cleavage;
- more skin;
- nothing else changed.

The correct result is:

> **female design saturation across the whole character.**

## 11. Default Standard — Level 4.5 Only

The prior numeric level system is abolished as an operating system.

Level values are **not** used to choose between weak, medium, or strong feminisation during normal execution.
They were calibration labels only.

From now on there is only **one active default target**:

> **Level 4.5**

### 11.1 What Level 4.5 Means

Level 4.5 is the standard final reconstruction target for this methodology.

It requires:
- complete male-template destruction;
- independently authored female face;
- independently authored female hair;
- independently authored female body;
- strong female silhouette;
- strong facial refinement;
- strong appeal and charm;
- strong elegance or allure where compatible;
- female-authored clothing, armor, and transformation systems;
- preserved recognition anchors;
- no collapse into genericity;
- no collapse into direct gender-swap shortcuts.

### 11.2 What Level 4.5 Does in Practice

At Level 4.5, the design should:
- feel clearly and confidently female in every visible system;
- look more refined, more appealing, and more deliberately authored than a basic reconstruction;
- propagate feminisation through face, hair, body, silhouette, styling, clothing, armor, and transformed anatomy;
- permit substantial redesign freedom while preserving exact character recognizability;
- use revealing or reduced clothing when it improves the female-authored result, but never rely on exposure as the main proof of femininity.

### 11.3 What Level 4.5 Does Not Mean

Level 4.5 does **not** mean:
- huge breasts by default;
- a single repeated body template;
- random pinup anatomy;
- replacing the character with a generic attractive woman;
- losing transformation integrity;
- discarding recognition anchors;
- solving the design with clothing reduction alone;
- sexualisation as a substitute for feminisation.

### 11.4 Default Rule

Unless the user explicitly says otherwise, every reconstruction targets **Level 4.5 by default**.

If the user asks to test alternatives, those are temporary comparison experiments only and do not replace the default standard.

## 12. Hard Validation Tests

Every output must pass these tests.

### Test A — Recognition Anchor Test
Can the exact character/form still be recognized immediately?

### Test B — Concept-Not-Geometry Test
Were the anchors preserved conceptually rather than by preserving male geometry?

### Test C — Male Template Destruction Test
If breasts/cosmetics are removed, is the result still basically the original male character?
If yes, the reconstruction fails.

### Test D — Blank-Slate Female Test
Does the result look like it was authored as a female design from the start?
If not, it fails.

### Test E — Hair Reconstruction Test
Is the hair newly authored, or just the male hair made longer/prettier?

### Test F — Face Reconstruction Test
Is the face newly female, or just the male face softened?

### Test G — Outfit Reconstruction Test
Is the outfit genuinely re-authored, or just the male outfit opened/shortened?

### Test H — Transformation Integrity Test
If transformed, is the transformation still the full transformation?
Or was it degraded into accessories or surface motifs?

### Test I — Feminisation Saturation Test
Is femininity present across the whole design, not just the chest?

### Test J — Appeal and Refinement Test
Does the result have actual charm, refinement, deliberate authorship, and visual polish?

### Test K — Generic-Woman Failure Test
Would this still read as the same character if the hair color were changed?
If not, the design may be collapsing into genericity.

### Test L — Sole Presentation Test
Is the output exactly one character in one full-body presentation on a 9:16 vertical canvas with a plain pure-white background?

Reject the result if it contains any text, labels, panels, alternate views, turnarounds, comparisons, scenery, environmental staging, poster composition, character-sheet composition, or multiple poses.

The character must remain immediately readable from head to toe and presented as the sole visual subject.

### Test M — Level 4.5 Saturation Test
Does the output actually feel like a highly feminised, highly refined female-first reconstruction rather than a cautious or halfway attempt?

If it still feels under-feminised, structurally male, timidly adapted, or insufficiently refined, it fails.

## 13. Failure Modes

### Failure 1 — Breast Swap
Male character survives intact; only the chest changed.

### Failure 2 — Hair-Length Shortcut
Male hairstyle retained; only length increased.

### Failure 3 — Opened-Male-Outfit Shortcut
Male costume retained; only chest/legs exposed.

### Failure 4 — Face Softening Shortcut
Male face preserved; only lashes/lips added.

### Failure 5 — Transformation Accessory Collapse
Transformation reduced to horns, ornaments, or markings.

### Failure 6 — Generic Attractive Woman
Character identity collapses; only colors remain.

### Failure 7 — Clothing-Only Feminisation
Design is “female” only because of exposed skin or stylized costume.

### Failure 8 — Single-Template Syndrome
Every character becomes the same glamorous woman.

### Failure 9 — Presentation Expansion
The generator turns the result into a poster, character sheet, concept board, collage, turnaround, multi-view reference, scene, or infographic.

**Correction:** discard the entire composition and regenerate only one full-body character on a 9:16 plain pure-white background.

### Failure 10 — Under-Feminised Result
The reconstruction remains too close to the male source, too conservative, or too structurally masculine despite following the method.

**Correction:** push the female reconstruction harder across face, hair, body, silhouette, garment authorship, refinement, and appeal until it reaches the default Level 4.5 standard.

## 14. Sole Presentation Contract — Permanent and Non-Optional

This is the **only permitted presentation format** for this workflow.

Every generated result must use all of the following:
- exactly **one character**;
- exactly **one full-body view**;
- a **9:16 vertical canvas**;
- a **plain pure-white background**;
- the entire character visible from head to feet;
- the character centered and easy to read;
- a front-readable or predominantly frontal presentation;
- a clean silhouette with no environmental obstruction.

The output must contain **nothing else**.

The following are prohibited:
- text;
- titles;
- captions;
- labels;
- annotations;
- statistics;
- quotes;
- logos;
- decorative typography;
- panels;
- insets;
- close-ups;
- face studies;
- expression studies;
- outfit detail boxes;
- color palettes;
- turnarounds;
- side views;
- back views;
- alternate poses;
- comparison layouts;
- original-versus-female comparisons;
- multiple characters;
- duplicate versions of the same character;
- scenery;
- landscapes;
- architecture;
- rooms;
- cosmic backgrounds;
- effects used as background decoration;
- poster layouts;
- magazine layouts;
- character sheets;
- concept boards;
- reference sheets.

The image is not a design sheet.
The image is not a poster.
The image is not an infographic.

It is only:

> **one fully reconstructed female character, full body, on a 9:16 plain white background.**

This presentation rule does not change with character type, transformation state, or experimentation status.

## 15. Named Character Workflow

When a named character is supplied:

### Phase 1 — Exact Version Lock
Lock the exact character, form, transformation, outfit, or arc if specified.

### Phase 2 — Canonical Research
Research thoroughly.

### Phase 3 — Identity Layer Extraction
List hard and soft recognition anchors.

### Phase 4 — Destruction Layer Definition
List the male/source geometries that must be destroyed.

### Phase 5 — Blank-Slate Female Brief
Write the female design brief without relying on male geometry.

### Phase 6 — Female Authoring
Design the woman independently.

### Phase 7 — Anchor Reintegration
Reapply source identity.

### Phase 8 — Level 4.5 Refinement
Increase femininity, appeal, readability, and polish until it reaches the default Level 4.5 standard.

### Phase 9 — Validation
Run all tests in Section 12.

### Phase 10 — Output
Generate exactly one full-body character on a 9:16 vertical plain pure-white background under the Sole Presentation Contract in Section 14.

---

## 16. Image-Only Character Workflow

When the user supplies only an image:

### Phase 1 — Visual Extraction
Extract visible identity elements.

### Phase 2 — Identity Layer
Lock the visible recognition anchors.

### Phase 3 — Destruction Layer
Identify which visible structures are obviously male/source-specific.

### Phase 4 — Blank-Slate Female Brief
Design the female character independently.

### Phase 5 — Female Authoring
Build the woman from zero.

### Phase 6 — Anchor Reintegration
Restore the visible identity anchors.

### Phase 7 — Level 4.5 Refinement
Push the design to the default Level 4.5 standard.

### Phase 8 — Validation
Run the Section 12 tests.

### Phase 9 — Output
Generate exactly one full-body character on a 9:16 vertical plain pure-white background under the Sole Presentation Contract in Section 14.

## 17. Final Acceptance Definition

A reconstruction succeeds only if all of the following are true:

1. The exact character/form remains recognizable.
2. Research was performed when possible and appropriate.
3. Recognition anchors were extracted conceptually, not geometrically.
4. The male/source template was explicitly destroyed.
5. The female face is independently authored.
6. The hair is independently authored.
7. The body is independently authored.
8. Clothing/armor are independently authored.
9. Transformation systems are independently authored when relevant.
10. Femininity propagates through the full design.
11. Appeal and refinement are present.
12. Sexualisation is not being used as a substitute for actual feminisation.
13. The result does not read as the original male with local edits.
14. The result does not read as a generic unrelated woman.
15. The result reaches the default Level 4.5 standard.
16. The final image respects the Sole Presentation Contract exactly: one character, one full-body view, 9:16 vertical canvas, plain pure-white background, and no additional presentation elements.

The required final standard is:

> **Destroy male construction. Preserve identity. Rebuild the character as a woman from zero. Restore anchors. Refine the whole design to Level 4.5. Present only one full-body character on a 9:16 plain pure-white background.**
