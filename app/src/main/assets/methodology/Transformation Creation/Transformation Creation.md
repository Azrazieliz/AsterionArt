# TRANSFORMATION CREATION — ABSOLUTE AUTHORITATIVE CREATIVE WORKFLOW

## Version 1.0 — Identity-Preserved / Alternate-Form / Structural-Transformation Workflow

**STATUS:** AUTHORITATIVE / STANDALONE / SAME-CHARACTER / IDENTITY-LOCKED / STRUCTURAL / HIGH-DIFFERENTIATION / IMAGE-CAPABLE

This document is the sole authoritative Transformation Creation workflow for the active conversation.

Its purpose is to transform an already-established character into a new alternate form while preserving enough immutable recognition structure that the result remains unmistakably the same individual.

Transformation changes the character.

Transformation does **not** replace the character.

---

# 0. HIGHEST-PRECEDENCE EXECUTION LOCK

Transformation Creation follows:

**SOURCE CHARACTER → IDENTITY-ANCHOR EXTRACTION → TRANSFORMATION DIRECTIVE → CHANGE-BUDGET DEFINITION → STRUCTURAL MATERIALISATION → CROSS-SYSTEM PROPAGATION → SILHOUETTE / COLOR / MATERIAL DIFFERENTIATION → RECOGNITION AUDIT → RENDER PREFLIGHT → IMAGE GENERATION → ACTUAL-IMAGE INSPECTION → USER SELECTION / REFINE / ALTER / FUSE / FREEZE**

The source character remains the same canonical individual throughout the transformation.

The workflow may substantially alter:

- anatomy;
- species traits;
- body materials;
- appendages;
- coloration;
- hair state;
- eyes;
- markings;
- outfit state;
- armor;
- energy-bearing structures;
- silhouette;
- apparent biological architecture;
- mechanical architecture;
- supernatural architecture.

But every transformation must preserve a deliberate set of recognition anchors.

If those anchors are lost, the result is a new character, not a transformation.

---

# 1. REQUIRED INPUT

A normal Transformation Creation task requires:

1. a source character authority;
2. a transformation directive, theme, concept, or desired form.

Valid source character authorities include:

- character illustration;
- Character Sheet;
- frozen Character Creation output;
- frozen Feminisation output;
- other explicit visual character reference.

Optional authorities:

- Outfit Creation result;
- Weapon Creation result;
- Art Style Sheet;
- transformation reference images;
- user-specified preservation constraints.

If several source images conflict, resolve the intended source form before transforming it.

Do not merge unrelated forms by accident.

# 2. CORE DEFINITION

A transformation is:

**the same individual reconstructed into a new physical or visual state through coherent structural change.**

A valid transformation may be:

- powered form;
- awakened form;
- corrupted form;
- purified form;
- divine form;
- demonic form;
- angelic form;
- monstrous form;
- feral form;
- mechanical form;
- biomechanical form;
- crystalline form;
- elemental form;
- spectral form;
- aquatic form;
- draconic form;
- insectoid form;
- plant-derived form;
- celestial form;
- void form;
- armored transformation;
- battle form;
- berserk form;
- parasitic form;
- fused-species form;
- cybernetic form;
- experimental form;
- concept-driven alternate morphology;
- other same-character alternate state.

Transformation may be subtle or radical.

The defining question is not “how much changed?”

It is:

**does the result remain recognizably the same individual?**

---

# 3. TRANSFORMATION VS MUTATION VS ALTERNATE UNIVERSE

This workflow is specifically for **Transformation**.

Transformation:
- same character;
- same continuity unless user says otherwise;
- deliberate alternate state/form;
- identity anchors preserved;
- changes can be large and systemic.

Mutation:
- stochastic or exploratory deviation;
- identity retention may be partial and parameterized;
- variation itself is the creative objective.

Alternate Universe:
- same character re-authored for a different world/setting;
- body identity is normally more stable;
- setting logic drives redesign.

Do not silently switch workflows.

---

# 4. IDENTITY-ANCHOR EXTRACTION — HARD / ABSOLUTE

Before designing the transformation, identify the source character's strongest recognition anchors.

Potential anchors include:

- face shape;
- eye spacing;
- eye geometry;
- signature eye color or pattern;
- bangs;
- hairline;
- hair silhouette;
- signature hair ornament;
- jaw/chin structure;
- body proportion relationship;
- height impression;
- shoulder/waist/hip relationship;
- signature scar;
- signature marking;
- species feature;
- asymmetry;
- horn layout;
- ear shape;
- appendage configuration;
- signature palette relationship;
- iconic clothing landmark;
- signature accessory;
- silhouette landmark;
- characteristic negative space;
- recurring geometric motif;
- weapon relationship.

Not every source trait must be frozen.

The workflow must distinguish:

## IMMUTABLE RECOGNITION ANCHORS
Traits that must survive strongly.

## FLEXIBLE IDENTITY FEATURES
Traits that may transform but should retain lineage.

## TRANSFORMABLE SYSTEMS
Traits explicitly available for major change.

A transformation may deliberately alter one normally strong anchor only if enough other anchors remain to preserve identity.

---

# 5. MINIMUM RECOGNITION REQUIREMENT

Every transformation must preserve multiple independent recognition channels.

At least three strong channels should normally survive, for example:

- face geometry;
- bangs / hairline;
- body proportion signature;
- eye structure;
- asymmetry;
- signature marking;
- silhouette landmark.

Do not rely on color alone.

Do not rely on one accessory alone.

Do not rely on one symbol alone.

If the transformed form is only recognizable because it has the same clothes or palette, identity preservation is too weak.

---

# 6. CHANGE-BUDGET SYSTEM

Every transformation has a change budget.

Default levels:

## LEVEL 1 — LIGHT
Minor but clear alternate state.

May affect:
- eyes;
- markings;
- hair state;
- small horns;
- localized material changes;
- outfit/armor accents;
- aura-bound structures;
- small appendages.

Body identity remains highly stable.

## LEVEL 2 — MODERATE
Major visible alternate form.

May affect:
- larger appendages;
- limb material;
- body markings;
- hair architecture;
- eyes;
- skin/material zones;
- partial armor growth;
- silhouette;
- localized anatomy.

Face and core body identity remain strongly preserved.

## LEVEL 3 — HEAVY
Radical transformation while retaining clear same-character identity.

May affect:
- species architecture;
- body substrate;
- horns;
- wings;
- tail;
- limb construction;
- torso structures;
- hair;
- palette;
- major silhouette;
- outfit integration.

Multiple identity anchors must remain explicit.

## LEVEL 4 — EXTREME
Near-total alternate morphology.

May affect almost every visible system.

Still requires deliberate preservation of enough face/head/marking/proportion/geometry anchors to remain the same individual.

A Level 4 result that reads as a new character fails.

The user may specify another scale.

---

# 7. TRANSFORMATION DIRECTIVE PARSING

A transformation directive must be converted into concrete visual systems.

Examples:

“void” may become:
- bounded dark material;
- internal negative-space structures;
- star-like embedded points;
- altered eye construction;
- hollow apertures;
- gradient edge dissolution;
- elongated or segmented appendages.

“dragon” may become:
- horn architecture;
- scale/plating distribution;
- wing system;
- tail;
- claw transformation;
- altered pupils;
- body-material transitions;
- heat-resistant or volcanic material language.

“mechanical” may become:
- articulated plates;
- mechanical joints;
- exposed linkage;
- synthetic materials;
- bounded luminous cores;
- segmented limbs;
- visible fastening architecture.

Do not stop at symbols, colors, or decorative effects.

The concept must materially transform the character.

---

# 8. STRUCTURAL MATERIALISATION — HARD

Transformation concepts must enter the body through actual structure.

Valid materialisation channels include:

- anatomy;
- surface material;
- body topology;
- appendages;
- skeletal/armor silhouette;
- hair architecture;
- eye architecture;
- mouth/teeth;
- hands/claws;
- feet;
- torso segmentation;
- embedded structures;
- protrusions;
- ridges;
- plates;
- cavities;
- apertures;
- tails;
- wings;
- horns;
- mechanical joints;
- internal luminous regions;
- persistent markings;
- coherent garment transformation.

A transformation that consists only of:
- recoloring;
- glow;
- aura;
- particles;
- symbols;
- background effects;
- added accessories;

is insufficient unless the user explicitly requests a very light transformation.

---

# 9. SYMBIOTIC TRANSFORMATION LOGIC

When several concepts are combined, they must interact.

Do not assign one concept to hair, one to clothes, and one to the background and call that fusion.

Concepts should alter each other.

Example:

**DRAGON × VOID**

Weak:
- dragon horns + black aura.

Strong:
- horn geometry contains hollow void-channel architecture;
- scales transition into matte negative-volume plates;
- wing membranes behave like bounded starless surfaces;
- pupils and apertures share one structural language;
- tail segmentation echoes void cavities.

The result should feel like one transformed biology/system rather than stacked motifs.

---

# 10. WHOLE-BODY PROPAGATION

A major transformation must propagate beyond one local feature.

Consider effects on:

- head;
- face;
- eyes;
- hair;
- neck;
- shoulders;
- arms;
- hands;
- torso;
- chest;
- waist;
- pelvis;
- hips;
- legs;
- feet;
- back;
- appendages;
- silhouette;
- surface materials;
- color distribution.

Not every region must change.

But the transformed state must feel coherent across the body.

---

# 11. FACE PRESERVATION AND TRANSFORMATION

The face is the highest-risk identity region.

Preserve enough of:

- face shape;
- jaw;
- chin;
- cheek placement;
- eye spacing;
- mouth placement;
- nose indication;
- brow placement;
- bangs-to-face relationship.

Allowed transformations may include:

- altered pupils;
- altered iris structure;
- sclera changes;
- markings;
- scales;
- cracks;
- mechanical seams;
- small horn bases;
- altered ear structure;
- localized material changes;
- controlled facial armor.

Do not replace the source face with a generic “demon face,” “robot face,” or “monster face.”

The transformed face must still be her face.

---

# 12. HAIR TRANSFORMATION

Hair may transform substantially while preserving lineage.

Possible changes:
- length;
- volume;
- levitation;
- segmentation;
- material change;
- luminous strands;
- crystalline sections;
- flame-like bounded structure;
- mechanical strand groups;
- wet/liquid-like structure;
- horn integration;
- alternate tied state.

Preserve at least some recognition structure where hair is identity-critical:
- bangs;
- parting;
- face-framing locks;
- hairline;
- ahoge;
- signature asymmetry;
- ornament position.

Do not substitute a generic fantasy hairstyle.

---

# 13. BODY MORPHOLOGY

Transformation may alter body morphology when appropriate.

Possible changes:
- musculature;
- limb proportion;
- torso mass;
- height impression;
- digit structure;
- clawing;
- leg architecture;
- feet;
- shoulder structure;
- ribcage silhouette;
- pelvis silhouette;
- extra limbs;
- partial non-human anatomy.

However:

- change must be intentional;
- recognition anchors must compensate;
- sex/gender presentation must not drift unintentionally;
- the result must not be normalized toward generic monster/anime anatomy.

Do not change bust/waist/hip proportions accidentally just because the transformation is dramatic.

---

# 14. APPENDAGE ARCHITECTURE

When adding:
- horns;
- wings;
- tails;
- extra arms;
- tendrils;
- fins;
- antennae;
- mechanical appendages;
- floating-but-attached systems;

resolve:

- root location;
- count;
- symmetry/asymmetry;
- scale;
- articulation;
- relation to body;
- silhouette;
- material;
- color;
- interaction with clothing;
- interaction with hair;
- occupied space.

Appendages must connect coherently.

Do not paste wings behind a character without resolving their roots.

---

# 15. BODY MATERIAL TRANSFORMATION

Possible body-material systems include:

- skin;
- scales;
- chitin;
- bone-like surfaces;
- stone;
- crystal;
- metal;
- glass-like matter;
- translucent matter;
- smoke-like bounded anatomy;
- liquid-like bounded anatomy;
- plant tissue;
- bark;
- biomechanical composite;
- synthetic shell;
- luminous coherent matter;
- void-like bounded matter.

When material changes are used, define:

- where they begin;
- where they end;
- transition geometry;
- thickness/edge behavior;
- highlights;
- opacity;
- texture;
- segmentation;
- color behavior.

A shader effect is not a structural transformation.

---

# 16. COLOR ARCHITECTURE — HARD

Transformations must not collapse into one-color bodies by default.

Within one transformed character, actively consider:

- base body color;
- secondary body material;
- tertiary material;
- hair;
- eyes;
- markings;
- appendages;
- armor/outfit;
- luminous regions;
- accents.

Use:
- bicolor systems;
- gradients;
- zoned color;
- complementary accents;
- material-dependent colors;
- internal luminous contrast;
- warm/cool separation;
- dark/light segmentation.

One flat color across hair, eyes, skin, horns, wings, outfit, and effects is normally a failure.

---

# 17. MATERIAL DIFFERENTIATION

Different structural systems should not all share one undifferentiated surface treatment.

For example:
- horn ≠ skin;
- wing membrane ≠ bone strut;
- crystal ≠ metal;
- scale ≠ cloth;
- mechanical joint ≠ armor plate.

Even when colors are related, material identity must remain readable.

---

# 18. SILHOUETTE TRANSFORMATION

A transformation should normally alter silhouette in a deliberate way.

Potential silhouette changes:
- horns;
- hair volume;
- shoulders;
- back structures;
- wings;
- tail;
- forearm architecture;
- leg architecture;
- coat/armor transformation;
- floating-but-bound components.

Do not make every transformation “bigger shoulders + bigger horns.”

Silhouette should follow the directive and character.

---

# 19. OUTFIT HANDLING

If no outfit is supplied:
- preserve the source clothing identity where appropriate;
- or transform it only when the transformation logically affects it.

If a frozen Outfit Creation result is supplied:
- treat it as preserved unless the user explicitly allows transformed outfit behavior.

Possible transformation relationships:
- outfit remains unchanged;
- outfit recolors/material-shifts;
- outfit partially transforms;
- outfit becomes damaged;
- outfit becomes integrated armor;
- outfit dissolves into transformed body material;
- outfit gains transformation-compatible openings.

Any outfit transformation must be explicit.

Do not silently delete clothing.

Do not silently redesign it.

---

# 20. WEAPON HANDLING

If a weapon is supplied:
- preserve it by default;
- transform it only if the user explicitly wants a transformed weapon.

A character transformation does not automatically authorize a weapon redesign.

If the weapon must adapt to changed hands/appendages, alter only the necessary interaction unless broader weapon transformation is authorized.

---

# 21. EFFECTS ARE SUBORDINATE

Effects may support:
- power;
- transformation state;
- movement;
- heat;
- cold;
- electricity;
- void;
- magic;
- corruption;
- radiance.

But effects cannot substitute for actual transformed anatomy or materials.

If removing the aura makes the character look essentially unchanged, the transformation is probably under-materialized.

---

# 22. TRANSFORMATION INTENSITY DISTRIBUTION

Do not distribute change evenly by default.

A strong transformation may use:
- one dominant transformed system;
- two secondary systems;
- smaller tertiary echoes.

Example:
dominant = biomechanical limb architecture;
secondary = eye/head integration;
secondary = spinal/back structures;
tertiary = markings/color transitions.

Hierarchy is better than indiscriminate full-body noise.

---

# 23. ASYMMETRY

Asymmetry may strengthen transformed identity.

Possible uses:
- one transformed arm;
- one horn larger;
- unilateral plating;
- one wing damaged;
- localized corruption;
- asymmetric face marking;
- one mechanical leg;
- side-biased material spread.

Asymmetry is optional.

Use it deliberately.

Do not accidentally create asymmetry through generation drift.

---

# 24. RECOGNITION VS NOVELTY BALANCE

Transformation quality requires both:

## NOVELTY
The alternate form must be meaningfully different.

## CONTINUITY
The source character must remain recognizable.

Too little novelty:
- recolor;
- aura;
- eye glow;
- tiny horns only.

Too little continuity:
- completely different face;
- different body identity;
- unrelated hair;
- unrelated proportions;
- generic monster replacement.

The target is **high change with controlled identity retention**.

---

# 25. DEFAULT CREATIVE CATALOGUE — FIVE FORMS

When the user broadly asks for transformation ideas without specifying one exact form, create **5 radically distinct transformation candidates**.

Why five rather than ten:
- transformations are whole-character designs;
- each candidate requires substantial visual space;
- identity must remain inspectable;
- body/material differences need full-body readability.

## Mandatory catalogue geometry
- one continuous exact **16:9 landscape** image;
- five full-body transformed character candidates;
- clean white or very light neutral background;
- candidates numbered 1–5;
- no narrative names;
- no lore blurbs;
- no environment;
- no extra characters;
- no decorative effects outside what is intrinsic to each form;
- each candidate complete and uncropped.

Use a consistent neutral or minimally posed stance so structural differences are comparable.

---

# 26. FIVE-FORM DIFFERENTIATION GATE

The five candidates must differ strongly across multiple axes:

- transformation logic;
- body-material architecture;
- silhouette;
- appendages;
- color system;
- hair transformation;
- eye transformation;
- anatomy distribution;
- asymmetry;
- outfit relationship;
- dominant transformed region.

Do not create five versions of:
- same horns;
- same black skin;
- same glowing eyes;
- different aura colors.

Each candidate should represent a distinct answer to the directive.

---

# 27. USER-DIRECTED SINGLE FORM

If the user gives a specific transformation directive, create one resolved form rather than a catalogue unless they ask for options.

Default output:
- 9:16 portrait;
- one full-body character;
- plain white/light-neutral background;
- neutral or minimally posed;
- complete silhouette visible;
- no environment;
- no text;
- no unrelated props;
- exact source identity preserved.

---

# 28. COMMAND ROUTING

## TRANSFORM: [directive]
Create one transformation from the directive.

## SUGGEST FORMS / TRANSFORMATIONS
Create the default five-candidate transformation catalogue.

## PREVIEW [candidate]
Render the selected form as a large 9:16 full-body presentation.

## REFINE [candidate/current]
Improve transformation coherence, materialization, differentiation, color, anatomy integration, and identity preservation without redesigning it into a different form.

## ALTER [candidate/current]: [instruction]
Change only the requested transformed systems and necessary dependencies.

## FUSE [A] + [B] (+ ...)
Create one coherent new transformation by structurally synthesizing selected forms.

## INTENSITY [1–4]
Rebuild the current transformation at the requested change-budget level while preserving its concept identity.

## VARIANTS [current]: [dimension]
Create controlled variants of the same transformation.

## REVERT [system]
Restore the named transformed system to the source-character state while preserving the rest of the transformation.

## FREEZE [candidate/current]
Freeze the selected transformed form for the active conversation.

---

# 29. FUSION QUALITY GATE

Transformation fusion operates at system level.

Potential inherited systems:
- face treatment;
- hair treatment;
- body material;
- appendage architecture;
- silhouette;
- color architecture;
- asymmetry;
- markings;
- transformed outfit behavior;
- eye architecture.

Do not collage parent forms.

Do not split the body into arbitrary A/B halves unless explicitly requested.

The fused transformation must develop one coherent higher-order physiology/visual system.

---

# 30. ALTERATION PRESERVATION GATE

ALTER changes only what is requested.

Examples:

- “make the wings larger” → preserve face, body material, hair, palette, and other systems;
- “remove the horns” → resolve head silhouette without redesigning the rest;
- “more crystalline” → increase crystal materialization in designated regions while preserving the form identity;
- “less monstrous” → selectively restore source morphology while keeping the transformation's defining systems;
- “make the eyes normal again” → restore source eye identity and preserve other transformed systems.

Do not opportunistically rebuild everything.

---

# 31. REFINEMENT GATE

REFINE is not REDESIGN.

Refinement may improve:

- concept symbiosis;
- transition zones;
- appendage roots;
- material boundaries;
- silhouette clarity;
- identity anchor visibility;
- color balance;
- asymmetry;
- anatomical coherence;
- detail hierarchy;
- render robustness.

The form must remain recognizably the same transformation.

---

# 32. REVERSION GATE

REVERT restores a transformed subsystem to the source-character state.

Examples:
- REVERT HAIR;
- REVERT EYES;
- REVERT LEFT ARM;
- REVERT SKIN;
- REVERT OUTFIT.

Only the named system and unavoidable transition zones may change.

This is not a full reset.

---

# 33. STYLE HANDLING

If an Art Style Sheet is supplied:

**ART STYLE SHEET = rendering authority only.**

The source character and transformation design remain content authorities.

If no Art Style Sheet is supplied, use a clean high-quality 2D anime/manhwa illustration style compatible with the source.

Do not let rendering style itself become the transformation.

---

# 34. GENERATOR HANDOFF

Before image generation, compile the transformation in this order:

1. source character identity anchors;
2. transformation directive;
3. change-budget level;
4. preserved systems;
5. transformed body systems;
6. face;
7. hair;
8. materials;
9. appendages;
10. silhouette;
11. color architecture;
12. outfit relationship;
13. weapon relationship if relevant;
14. exact output geometry;
15. exclusions preventing identity drift.

The renderer must not decide unresolved transformation logic.

---

# 35. ACTUAL-IMAGE INSPECTION

After generation, inspect the actual image.

Check:

- same individual still recognizable;
- face anchors preserved;
- hair lineage preserved where required;
- body identity intentionally changed rather than accidentally drifted;
- transformation clearly materialized;
- concept not reduced to effects;
- appendages rooted coherently;
- material transitions clear;
- body systems differentiated;
- color architecture varied and intentional;
- silhouette transformed;
- outfit handling correct;
- weapon handling correct;
- no extra character;
- no accidental alternate identity;
- no generic demon/angel/robot substitution;
- output geometry correct;
- no crop of critical anatomy.

Do not assume prompt compliance.

---

# 36. FAILURE CONDITIONS — HARD

A transformation fails if any of the following occurs:

- character becomes a different person;
- face replaced by generic transformed archetype;
- all recognition anchors lost;
- transformation exists only as recolor/effects without authorization;
- concepts remain separate decorative motifs instead of integrated systems;
- appended wings/horns/tails lack coherent roots;
- body materials read only as shaders;
- one flat color dominates every body system by default;
- transformed anatomy is incoherent;
- sex/gender presentation drifts unintentionally;
- outfit silently disappears or redesigns;
- weapon silently redesigns;
- source proportions drift without intentional transformation logic;
- five candidates are near-duplicates;
- silhouette unchanged in a supposedly major transformation;
- generic anime monster normalization;
- transformed features inconsistent across the body;
- extra characters;
- incorrect aspect ratio / catalogue structure;
- important anatomy cropped.

Pre-generation failure:
**STOP → REDESIGN → REVALIDATE → GENERATE.**

Post-generation failure:
record the actual failure and do not pretend it passed.

---

# 37. FREEZE SEMANTICS

A frozen transformation locks:

- source character identity anchors;
- transformation directive;
- intensity/change budget;
- transformed anatomy;
- preserved anatomy;
- face treatment;
- eye treatment;
- hair state;
- body materials;
- appendages;
- silhouette;
- color architecture;
- markings;
- asymmetry;
- outfit relationship;
- weapon relationship;
- identity-defining transformed details.

Freeze prevents silent drift.

Explicit ALTER, REFINE, FUSE, INTENSITY, VARIANTS, REVERT, or new TRANSFORM commands may create a new revision.

---

# 38. FINAL ACCEPTANCE STANDARD

A successful transformation must be simultaneously:

- recognizably the same individual;
- meaningfully different;
- structurally transformed;
- conceptually coherent;
- materially resolved;
- visually memorable;
- color-authored;
- silhouette-distinct;
- anatomically integrated;
- non-generic;
- reproducible.

The strongest result should make the viewer think:

**“That is unmistakably the same character in a radically different form.”**

Not:

**“That is a different character with similar colors.”**

And not:

**“That is the same character with an aura.”**

---

# 39. FINAL COMMAND

For every Transformation Creation task:

**Identify the source character first.  
Freeze recognition anchors.  
Define how much may change.  
Translate concepts into structure.  
Propagate transformation coherently across the body.  
Integrate concepts rather than stacking motifs.  
Preserve face and identity intentionally.  
Use material and color differentiation aggressively.  
Transform silhouette deliberately.  
Keep effects subordinate to actual morphology.  
Render only resolved forms.  
Inspect the actual result.  
Reject both under-transformation and identity replacement.  
Freeze accepted forms against silent drift.**

The target is:

**the same character, transformed deeply enough to feel like a true alternate form, but preserved strongly enough to remain unmistakably herself.**
