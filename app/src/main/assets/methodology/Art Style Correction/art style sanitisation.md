# ART STYLE SANITISATION --- ABSOLUTE AUTHORITATIVE WORKFLOW

## Version 1.0 --- Exact Style Re-Rendering Standard

The following rules are the sole authoritative operating standard for Art Style
Sanitisation tasks in this conversation.

Every rule is mandatory.

No rule may be weakened, silently ignored, reinterpreted, generalized,
substituted, or overridden by convenience, aesthetic preference, prior habit,
model tendency, or inferred intent.

------------------------------------------------------------------------

## 0. ABSOLUTE OPERATING PRINCIPLE

Art Style Sanitisation is a **style-controlled redraw workflow**.

Its purpose is:

**Take one or more source illustrations and redraw them so that they are
rendered fully, cleanly, and consistently in the target art style defined by
the supplied Art Style Sheet, while preserving the source illustration's
identity, design, pose, composition, and scene content unless the user
explicitly requests changes.**

It is **not**:

- a redesign workflow
- a character-creation workflow
- a feminisation workflow
- a prompt-writing workflow
- a loose inspiration workflow
- a style-mixing workflow
- a partial correction workflow
- a generic "make it similar" workflow

Its purpose is:

**sanitize the rendering style of the source illustration(s) so that the final
image(s) look as if they were originally drawn in the target style.**

------------------------------------------------------------------------

## 1. REQUIRED INPUTS

A valid Art Style Sanitisation task normally contains:

1. this workflow document
2. one authoritative Art Style Sheet
3. one or more source illustrations to redraw

The Art Style Sheet is mandatory unless the user explicitly instructs
otherwise.

The source illustration(s) are mandatory.

No Art Style Sanitisation task may be executed by guessing the target style
without a style authority if the user said the style is defined by an Art Style
Sheet.

------------------------------------------------------------------------

## 2. TWO-SOURCE GOVERNANCE MODEL

Art Style Sanitisation uses a strict two-source model.

### Source A --- Art Style Sheet
This governs the **target rendering language**.

### Source B --- Source Illustration(s)
These govern the **content to be redrawn**.

These two sources have different jobs and must never be conflated.

------------------------------------------------------------------------

## 3. ROLE OF THE ART STYLE SHEET

The Art Style Sheet is the sole authority for the target rendering style.

It governs, where visible and applicable:

- line behavior
- line thickness
- edge softness or sharpness
- face rendering style
- eye rendering style
- eyelash treatment
- nose indication style
- mouth rendering style
- hair rendering style
- strand simplification vs strand density
- anatomy stylisation language
- body rendering style
- hand rendering style
- skin rendering treatment
- shading logic
- highlight logic
- contrast handling
- color treatment
- palette behavior
- saturation behavior
- material rendering language
- cloth rendering language
- metal rendering language
- leather / latex / fur / mechanical rendering language where relevant
- lighting treatment
- texture handling
- polish level
- detail density
- overall finish quality
- rendering discipline
- background treatment style if a background exists
- effect rendering style if effects exist

The Art Style Sheet does **not** automatically govern:

- the identity of the source character
- the source pose
- the source outfit
- the source composition
- the source camera framing
- the source prop placement
- the source scene structure

unless the user explicitly says to inherit one of those from the style sheet.

------------------------------------------------------------------------

## 4. ROLE OF THE SOURCE ILLUSTRATION

The source illustration is the authority for what is being redrawn.

It governs, unless the user explicitly requests changes:

- character identity
- character count
- body type
- sex/gender presentation
- hairstyle design
- facial structure
- expression
- outfit design
- armor design
- accessory design
- weapon design
- prop design
- pose
- gesture
- hand placement
- body orientation
- camera angle
- framing
- crop
- scene composition
- background content
- object placement
- relative scale relationships
- scene intent
- lighting scenario
- action state
- emotional read
- visible anatomy
- visible silhouette
- all content-specific visible information

The source illustration defines **what the image is**.

The Art Style Sheet defines **how the image must be rendered**.

------------------------------------------------------------------------

## 5. HARD SEPARATION BETWEEN CONTENT AND STYLE

This distinction is mandatory.

### Content Layer
What is depicted.

### Style Layer
How it is rendered.

Art Style Sanitisation must preserve the Content Layer while replacing the Style
Layer.

Do not use the style transfer task as permission to redesign, recompose,
simplify, beautify, or reinterpret the underlying content.

------------------------------------------------------------------------

## 6. NO STYLE HYBRIDISATION

This workflow forbids style blending unless the user explicitly requests it.

Do not produce:

- partial style transfer
- weak style influence
- mixed-source rendering
- "mostly the same but somewhat cleaner"
- style contamination from the source image
- style contamination from prior outputs
- style contamination from unrelated house style defaults

The finished image must read as:

**the original illustration redrawn in the target style.**

Not:

**the original illustration with some target-style influence.**

------------------------------------------------------------------------

## 7. SOURCE STYLE DESTRUCTION IS MANDATORY

The rendering style present in the source illustration must not be preserved as
a competing visual system.

Preserve the subject matter.

Do not preserve the old rendering grammar.

Destroy and replace the following, where necessary:

- original line language
- original brush logic
- original shading logic
- original eye rendering style
- original hair rendering style
- original anatomy stylisation language
- original color handling
- original material rendering treatment
- original texture behavior
- original background rendering language

The source image survives as **content**, not as a coequal style authority.

------------------------------------------------------------------------

## 8. ART STYLE SHEET PARSING IS MANDATORY

Before sanitising a source illustration, the Art Style Sheet must be parsed
internally and resolved into a usable style specification.

The assistant must identify, where applicable:

- shape language
- facial stylisation
- eye structure and rendering
- hair rendering logic
- line discipline
- shading structure
- specular treatment
- material treatment
- color logic
- lighting discipline
- texture density
- finish level
- ornamental density
- compositional calm vs intensity
- edge cleanup behavior
- detail simplification rules
- detail emphasis rules
- background treatment rules
- effect rendering rules

The finished sanitised image does not need to expose this analysis.

------------------------------------------------------------------------

## 9. SOURCE ILLUSTRATION PARSING IS MANDATORY

Before sanitising a source illustration, the assistant must identify the
content anchors that must be preserved.

These include, where applicable:

- exact depicted character
- face geometry
- hairstyle design
- body structure
- proportions
- silhouette
- outfit/armor design
- props/weapons
- accessories
- pose
- gesture
- framing
- background structure
- scene depth
- relative positioning
- expression
- visible narrative action

Nothing identity-relevant may be carelessly changed during sanitisation.

------------------------------------------------------------------------

## 10. PRESERVATION STANDARD

By default, the sanitised image must preserve the source illustration as
faithfully as possible, while changing only the rendering language.

Preserve unless explicitly requested otherwise:

- same character
- same outfit
- same body
- same pose
- same camera
- same crop
- same scene
- same objects
- same visual emphasis
- same action beat
- same mood
- same expression
- same image purpose

The user asked for a redraw in the target style, not a new interpretation.

------------------------------------------------------------------------

## 11. EXACTNESS RULE

"Exactly" in this workflow means:

**preserve the depicted visual content as closely as possible while fully
rebuilding the rendering according to the target Art Style Sheet.**

This does not mean pixel tracing.

This does not mean keeping the old style.

This means:

- same illustration content
- same identity
- same construction
- same compositional logic
- same intent
- target-style rendering throughout

------------------------------------------------------------------------

## 12. CHARACTER CREATION / FEMINISATION SOURCE RULE

When the source illustration was created through the Character Creation workflow
or the feminisation workflow, the generated character result is binding as the
content source unless the user explicitly requests content changes.

Therefore, during Art Style Sanitisation, do **not** independently alter:

- reconstructed sex/gender presentation
- feminised identity result
- character design decisions
- anatomy decisions
- outfit decisions
- silhouette decisions
- recognition-anchor traits
- species traits
- hairstyle design
- accessories
- composition

The Art Style Sanitisation workflow does not override the underlying character
result.

It only redraws that result in the target style.

------------------------------------------------------------------------

## 13. MULTI-IMAGE CONSISTENCY

When multiple source illustrations are sanitised using the same Art Style Sheet,
all outputs must share the same target rendering language.

They must remain consistent in:

- line quality
- face rendering style
- eye rendering style
- hair rendering treatment
- shading logic
- material rendering logic
- finish level
- texture behavior
- effect language
- palette logic
- background treatment logic
- overall polish

The source illustrations may differ in pose, costume, crop, lighting, or scene.
The target style must remain stable.

------------------------------------------------------------------------

## 14. STYLE MUST DOMINATE, CONTENT MUST SURVIVE

The workflow target is:

- target style fully established
- source content fully preserved

Do not sacrifice content in order to over-display style.

Do not weaken style in order to over-preserve source rendering artifacts.

Both conditions must be true simultaneously.

------------------------------------------------------------------------

## 15. NO CONTENT DRIFT

The following are forbidden unless explicitly requested by the user:

- changing the character's face
- changing body proportions
- changing breast size
- changing waist or hips
- changing hairstyle
- changing outfit structure
- changing armor structure
- changing prop scale
- changing weapon design
- changing pose
- changing hand count or finger arrangement
- changing crop
- changing background content
- changing scene intent
- changing expression
- changing the number of visible objects
- changing sexualisation level
- changing modesty/exposure level
- changing the scene's visual beat

Style change is allowed.

Content drift is not.

------------------------------------------------------------------------

## 16. SANITISATION DOES NOT INVENT NEW INFORMATION

Do not invent hidden content.

Do not use style transfer as permission to fabricate:

- hidden anatomy
- hidden outfit layers
- unseen weapon construction
- new accessories
- extra objects
- different background structures
- altered props
- unsupported alternate viewpoints

If the source content is ambiguous, reconstruct conservatively.

Preserve uncertainty where necessary rather than redesigning.

------------------------------------------------------------------------

## 17. STYLE SHEET MUST NOT LEAK ITS OWN CHARACTER

If the Art Style Sheet is built around a specific example character, that
character's identity must not leak into the sanitised result.

Use the sheet to extract the rendering language, not to copy the sheet's
character.

Do not import:

- the sheet character's face
- the sheet character's body
- the sheet character's outfit
- the sheet character's accessories
- the sheet character's species traits
- the sheet character's props

unless the source illustration itself contains them.

------------------------------------------------------------------------

## 18. FACE PRESERVATION RULE

Faces are high-risk failure points.

When sanitising, preserve:

- face shape
- jaw
- chin
- cheek structure
- eye spacing
- eye size relation
- eyebrow placement
- nose indication
- mouth placement
- identifiable expression geometry
- bangs-to-face relationship

Translate the face into the target style without replacing the identity.

The face must still read as the same character.

------------------------------------------------------------------------

## 19. HAIR PRESERVATION RULE

When sanitising, preserve:

- hairstyle architecture
- bangs
- parting
- fringe grouping
- side locks
- overall volume
- length
- curl / wave / straightness
- ornaments
- accessory placement
- silhouette contribution

Redraw the hair in the target style.

Do not silently replace the hairstyle with the Art Style Sheet example hairstyle.

------------------------------------------------------------------------

## 20. BODY PRESERVATION RULE

When sanitising, preserve:

- body type
- body proportions
- silhouette
- limb length relationships
- chest size
- waist shape
- hip structure
- posture
- gesture
- species anatomy
- visible physical distinguishing traits

Translate the anatomy into the target style.

Do not redesign the body.

------------------------------------------------------------------------

## 21. OUTFIT / ARMOR / ACCESSORY PRESERVATION RULE

When sanitising, preserve:

- garment shapes
- armor construction
- layer relationships
- accessory placement
- closures
- ornamentation
- seams where visible
- footwear type
- glove type
- headwear
- belts / straps / buckles
- jewelry / ribbons / insignia
- weapon attachment

The target style may change how these are rendered.

It must not change what they are.

------------------------------------------------------------------------

## 22. PROP / WEAPON PRESERVATION RULE

When a source illustration contains a signature prop or weapon, preserve:

- silhouette
- size relation
- shape
- orientation
- placement
- visible detail logic
- material identity

Translate rendering only.

Do not replace the weapon/prop with a generic stylised equivalent.

------------------------------------------------------------------------

## 23. POSE / COMPOSITION / CAMERA PRESERVATION RULE

By default, preserve:

- pose
- body orientation
- gesture
- camera angle
- focal composition
- crop
- scene framing
- object positions
- background depth logic

Do not turn the task into a recomposition or re-staging task.

A redraw is not a remake.

------------------------------------------------------------------------

## 24. BACKGROUND RULE

If the source image contains a background, preserve the background content and
composition unless the user explicitly requests its removal or simplification.

The background must be redrawn in the target style.

Do not:

- invent a new environment
- delete meaningful background content
- replace it with a blank background
- replace it with generic effects

unless the user explicitly asks for that.

------------------------------------------------------------------------

## 25. COLOR RULE

The source illustration governs local object identity colors.

The Art Style Sheet governs how color is handled stylistically.

Therefore preserve:

- character hair color
- eye color
- skin tone family
- outfit colors
- prop colors
- environment colors
- lighting mood

while translating them through the target style's:

- saturation behavior
- contrast behavior
- edge behavior
- highlight behavior
- rendering finish
- palette discipline

Do not recolor the image to match the sheet character.

------------------------------------------------------------------------

## 26. LIGHTING RULE

Preserve the source scene's lighting intent unless the user requests otherwise.

The Art Style Sheet governs the rendering treatment of light, not automatic
relighting into a different scene logic.

For example:

- a soft-lit scene remains soft-lit
- a dramatic-lit scene remains dramatic-lit
- a night scene remains a night scene

but the way light is rendered must match the target style.

------------------------------------------------------------------------

## 27. DETAIL DENSITY RULE

The target Art Style Sheet governs the density and finish of detail.

If the target style is cleaner, cleaner rendering is allowed.

If the target style is denser, denser rendering is allowed.

However, detail-density translation must not destroy source content.

Simplify rendering when the style demands it.

Do not simplify identity-critical structure away.

------------------------------------------------------------------------

## 28. EFFECTS RULE

If the source illustration contains:

- magic effects
- smoke
- sparks
- glows
- particles
- motion accents
- energy
- aura
- atmosphere

preserve their presence and general function unless the user requests otherwise.

Render them in the target style.

Do not invent new effects merely because the style sheet supports them.

------------------------------------------------------------------------

## 29. MULTI-SOURCE TASKS

When sanitising several source illustrations in one task:

- all must use the same target style authority
- each image must preserve its own original content
- cross-image style consistency is mandatory
- cross-image content must not bleed incorrectly from one source image to another

One source illustration must not contaminate the content of another.

------------------------------------------------------------------------

## 30. NO BEAUTIFICATION DRIFT

Do not use style sanitisation as permission to "improve" the source
illustration by altering:

- attractiveness
- sex appeal
- anatomy
- exposure
- symmetry
- body shape
- facial appeal
- expression intensity
- glamour level

unless the user explicitly asks for those content changes.

Style sanitisation is not a hidden redesign pass.

------------------------------------------------------------------------

## 31. NO GENERIC MODEL OVERRIDE

Do not let generic model defaults replace the requested style.

Forbidden failure modes include:

- generic anime face substitution
- generic anime eyes
- generic hair rendering
- generic cell-shaded fallback
- generic soft-render fallback
- generic glossy finish
- generic fantasy illustration house style
- generic semirealistic drift

The target style must be visibly, specifically enforced.

------------------------------------------------------------------------

## 32. NO WEAK STYLE APPLICATION

A result fails if it looks merely "influenced by" the Art Style Sheet.

The result must read as a clean redraw in the target style.

Weak transfer is failure.

Partial transfer is failure.

Residual old style dominance is failure.

------------------------------------------------------------------------

## 33. INTERNAL EXECUTION PIPELINE

Every Art Style Sanitisation task must internally follow this sequence:

### Stage 1 --- Parse Workflow
Resolve the full operative rules.

### Stage 2 --- Parse Art Style Sheet
Extract the target style specification.

### Stage 3 --- Parse Source Illustration(s)
Extract the content anchors to preserve.

### Stage 4 --- Destroy Source Rendering Style
Separate content from rendering.

### Stage 5 --- Reconstruct in Target Style
Redraw the source content fully in the target style.

### Stage 6 --- Cross-Check
Compare output against both authorities:
- style sheet for rendering
- source illustration for content

### Stage 7 --- Final Verification
Accept only if both content preservation and style conformity are satisfied.

------------------------------------------------------------------------

## 34. DEFAULT OUTPUT CONTRACT

Unless the user requests otherwise:

- output one sanitised illustration per source illustration
- preserve the original image's aspect ratio
- preserve the original illustration's framing
- preserve the source scene content
- redraw the image fully in the target style
- do not output intermediate analysis
- do not output a hybrid
- do not output a style study instead of the final redraw

------------------------------------------------------------------------

## 35. FINAL VERIFICATION --- STYLE

Before accepting the result, confirm:

- the Art Style Sheet clearly governs the rendering
- face rendering matches the target style
- eyes match the target style
- hair rendering matches the target style
- shading matches the target style
- materials match the target style
- finish quality matches the target style
- background rendering matches the target style where applicable
- the old source style is no longer dominant
- no generic fallback style has replaced the target style

------------------------------------------------------------------------

## 36. FINAL VERIFICATION --- CONTENT

Before accepting the result, confirm:

- same character
- same face identity
- same hairstyle design
- same outfit design
- same accessories
- same weapon/prop design
- same body type
- same pose
- same expression
- same crop
- same camera
- same composition
- same scene intent
- same background content where applicable

------------------------------------------------------------------------

## 37. FINAL VERIFICATION --- MULTI-IMAGE CONSISTENCY

When multiple images are sanitized together, confirm:

- style is stable across all outputs
- rendering discipline is stable across all outputs
- no source image contaminated another's content
- no one image drifted into a different style

------------------------------------------------------------------------

## 38. ABSOLUTE FAILURE CONDITIONS

The result must be considered failed and redone if it contains any of the
following:

- source content redesigned without request
- wrong character identity
- face drift
- hairstyle drift
- body drift
- outfit drift
- prop/weapon drift
- pose drift
- composition drift
- background drift
- lost scene content
- style hybridisation
- weak style application
- residual dominance of the source style
- leakage of the Art Style Sheet example character into the result
- recoloring into the sheet character's palette
- generic anime fallback style
- beautification drift
- unintended sensuality increase or decrease
- unintended modesty/exposure change
- invented details
- removed details that should have remained
- cross-image inconsistency
- failure to preserve source framing
- failure to preserve source crop
- failure to preserve source scene logic

------------------------------------------------------------------------

## 39. FINAL COMMAND

Treat this methodology as the governing specification for every Art Style
Sanitisation task under this directive.

Do not reinterpret its purpose.

Do not weaken its preservation rules.

Do not turn redraw into redesign.

Do not turn target style into vague inspiration.

Do not blend styles unless explicitly requested.

Do not let source rendering survive as a competing style.

Do not let the Art Style Sheet example character leak into the sanitised result.

Do not let generic model defaults override either authority.

Preserve source content.

Apply target style fully.

Redraw exactly.

------------------------------------------------------------------------

## 40. CORE OPERATING FORMULA

The governing formula is:

**SOURCE ILLUSTRATION = content authority.**  
**ART STYLE SHEET = style authority.**  
**FINAL OUTPUT = source content redrawn fully in target style.**

Nothing else.
