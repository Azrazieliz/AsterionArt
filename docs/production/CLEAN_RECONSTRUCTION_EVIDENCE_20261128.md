## CPU reference-conditioning experiment

The experiment learned a mapping from a compact 512-wide visual encoder into the 1,024-wide input of a pretrained SD 1.5 IP-Adapter. It used 48 Cleveland Museum of Art CC0 works for fitting, 32 distinct held-out works, and 9 examples from excluded motifs. The fitted ONNX graph matched the NumPy projection with maximum absolute error below `1e-6`. The teacher model and the encoder revisions are pinned in the experiment receipt.

The reconstructed Java CPU graph runner executed both ONNX graphs with the exact benchmark reference on Linux and reproduced the `[1, 1024]` tensor from Python with zero observed difference. The debug Android app exposes the same graph runner for a staged reference-projection check.

| Evaluation split | Learned projection top-1 retrieval | Constant teacher-mean baseline |
| --- | ---: | ---: |
| Held-out works | 15/32 | 1/32 |
| Unseen motifs | 7/9 | 1/9 |

Same request, seed, scheduler and dimensions for each DreamShaper 8 render of an Orchid × Moth outfit. The reference was Cleveland object 173665, `Orchid Blossoms`. The cosine scores use the compact vision model and measure whole-frame reference similarity.

| Condition | Reference cosine | CPU render time |
| --- | ---: | ---: |
| Text only | 0.494 | 33.0 s |
| Full visual encoder | 0.670 | 31.1 s |
| Learned compact projection | 0.643 | 31.8 s |
| Learned projection with garment-region attention | 0.526 | 42.5 s |

Global conditioning carried the source's botanical surroundings into the background. Regional attention retained more of the neutral studio composition and kept visual influence on the garment. The comparison is one seed with a limited visual encoder and offers no owner preference result. An additional Anime Waifu Diffusion trial produced a cropped two-view Character board with unwanted clothing and an Outfit image with duplicated anatomy. Those outputs fail the relevant readiness checks. Neither experiment selects a production foundation.
