## Implemented native Anima contract

The C++ bridge is pinned to stable-diffusion.cpp `58d1126febec89040ead4e136d7467a0e6fe6746`. [Native source and patch](../../app/src/main/cpp/) · [Android bridge](../../app/src/main/kotlin/com/asterion/art/runtime/NativeAnima.kt)

1. The user's exact direction can enter Anima's Qwen and T5 text conditioning once. The graph uses raw encoding and preserves the applied tokens. Short sequences retain the existing padding behavior. The patch removes the upstream slice at 512 adapted positions. Long-context visual realization still requires a controlled image-level test.
2. Each learned input has its own `[tokens, 1024]` bank plus a patch mask for the selected region. The Anima cross-attention block computes its existing text attention and adds one separate K/V attention contribution per reference. A reference with a zero mask adds zero. Reusing the image query and output projection avoids repeating the entire denoiser for every reference. Denoising starts from noise and the VAE decodes the new image.
3. The experimental reference-conditioning learner has a shared 128-wide GELU/LayerNorm layer and two independently supervised heads. A head lifts its predicted coordinates to four positions in the receiving checkpoint's 1,024-wide adapted context. The active Anime trainer requires verified Anime images with separately annotated visible motif and surface. This supervision fits the receiving interface. Character identity, full artistic style reproduction and composition understanding require their own labels and tests.
4. The native C API uses structured float inputs. Reference images are encoded independently before being passed into the bridge. The patch keeps per-region attention separate from the native text context and preserves the existing unconditioned branch. Image and geometry shape checks fail visibly. The Android build can include the ARM64 renderer without changing Art's package identity. Vulkan and Qualcomm capabilities require actual device results.

## Shared artist comparison and Qwen's current boundary

The `Qwen3-0.6B-Base` artifact in the Anima test is the upstream text tower. It emits 1,024-wide features for the Anima adapter. It performs a forward evaluation of the owner's text, with the foundation's T5 tokenizer supplying target positions. The C++ bridge performs no autoregressive Qwen generation, methodology interpretation, design authorship, reference analysis or prompt rewriting. [Anima component documentation](https://github.com/leejet/stable-diffusion.cpp/blob/58d1126febec89040ead4e136d7467a0e6fe6746/docs/models/anima.md)

The historical v0.2.3 used Qwen3-1.7B Q4_K_M configured with 16,384 tokens for preparation. A Creature request reached a 10-second Android input-dispatch ANR and produced no creation. Available logs leave the root cause unresolved. The current Anima route performs a Qwen3-0.6B-Base encoding pass on the owner input as one renderer component. Image preparation and denoising run off the UI thread in the study. The backend releases model components after their last graph use and supports cooperative cancellation. Phone speed and model residency limits remain untested. Full foundation training is unnecessary for the first experiments. Distillation transfers supported behavior to smaller learners. LoRA changes selected matrices while keeping the underlying checkpoint. Projection fitting maps source features into the receiver's architecture. ## Native methodology inference

The queue owns workflow transitions, loads the specialist selected by the mode, and records the exact model, inputs and output until the next verified checkpoint. Learned operators own creative alternatives, composition, compatibility and the decision fields they produce. The author should use bounded depth tuned by measured difficulty, reference conflict and expected improvement. More difficult cases can spend more internal search or refinement; simple cases reuse stable high-confidence representations. Creative instructions retain their intended semantics.

Natural language belongs at human editing surfaces, text-native Themes and source descriptions. User direction can remain a direct native text input. Foundation-specific text tags or templates are used only where their effects are measured and their input text can be preserved. Internal methodology instructions do not run at inference. The artist's design reaches the renderer as bound learned semantics, separate visual banks, identity features, spatial weights and a persisted structured state. Optional authored field descriptions are editable, traceable and distinct from renderer conditioning. Validation measures whether each required fact is realized in pixels, including late and regional information.

## Personal catalogue and validation sets

Nexus remains the authority for rating and originals. The native provider grants read-only original access by hash after explicit selection. Current source exposes per-file name, MIME and size through that URI. It does not enumerate the collection or expose appreciation through that interface. Core's `ailm_android.sqlite` stores dimensions, tags and IDs, and `fusion_image_profiles` distinguishes an explicitly set 0–100 score from the default zero using `precision_overall_set`. The metadata-only index supports a supplied authorized snapshot without opening any original. It verifies fingerprint size, preserves exact identities, counts available rating/grouping metadata and tracks permission by source, hash and competency. Acquire measured subsets for each training stage. A selection needs provenance, digest and recorded granted purpose. Stream or stage into bounded cache, retain originals in Nexus and keep small versioned manifests and features on D:. Retire revoked or changed asset versions. Use exact duplicates and then validated perceptual groups, subject and creator to prevent leakage. Pair high and low appreciation for preference. Seek diverse successful Anime designs, coherent materials, strong silhouettes, expressive style, well-composed environments and challenging failures for Anime learning. For every model change retain source, exact sample memberships and splits, training counts, effective context, operator support, device wall time, peak memory, storage and computed fidelity per governed role. Verify with real images and independent artistic assessment. A small change can advance automatically only with demonstrated improvement, compatibility checks and rollback. A major model, methodology or taxonomy change retains owner review.
