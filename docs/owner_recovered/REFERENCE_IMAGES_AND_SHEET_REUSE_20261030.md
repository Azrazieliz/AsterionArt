**Character Sheet V5 non-negotiable:** one complete 9:16 portrait, one final native generation call, no collage of individually generated panel images. Canonical primary view, consistent face, eye, hair, anatomy, applicable default outfit, signature equipment, material details and palette follow the source facts. Original Character Creation Phase 1 has no invented outfit; its future Character Sheet specializes the anatomy/identity modules accordingly.

**Theme Sheet:** the user images are *thematic design-system boards*, not character-identity sheets. Preserve composition/interaction logic, constraints, visual material behavior, physical hierarchy, camera and environment. Do not generalize the role to a character sheet.

**Art Style/Element:** separately governed by their own original documents. The Character Sheet's visual quality and restrained alignment may inspire the presentation but cannot replace the separate semantics.

**Feminisation:** create a female-first independent design preserving recognizability; the two accepted presentations are not text presets and cannot replace actual model generation.

## Integration rules

- Select completed Original design in Design Library → **Create reference sheet** → select Character / Theme / Art Style / Element → **Generate sheet**.
- Source URI points to the exact selected generated image, never the complete multi-design sheet instead of a candidate and never a parent prompt.
- The new sheet is a separate neural reconstruction job; originating Original remains intact.
- No automatic generation of many expensive sheets merely because a catalogue completed.
- A Character Sheet cannot fall back to stitched panels when one-shot native context fails.
- No owner grades are inferred from creation, selection or conversion.
